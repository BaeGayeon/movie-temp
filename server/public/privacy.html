개인정보처리방침

bae-movie-temp (배무템) · 시행일: 2026-10-13 · English

bae-movie-temp(이하 "서비스")는 각자의 계정으로 영상을 재생하면서 재생 상태(재생·정지·이동)만 맞춰 주는 크롬 확장 프로그램과 동기화 서버입니다. 서비스는 회원가입과 로그인이 없고, 영상 자체나 사용자의 OTT 계정 정보(아이디, 비밀번호, 결제 정보 등)를 수집하거나 전송하지 않습니다.

1. 서버로 전송되는 정보

방을 만들거나 방에 참가하면 아래 정보가 동기화 서버로 전송되어 같은 방 사람들에게 전달됩니다.

정보용도
무작위로 만든 사용자 식별자(설치할 때 확장 프로그램이 생성)방 안에서 사용자 구분, 연결이 끊긴 뒤 다시 접속
닉네임, 프로필 이모지 또는 프로필 사진(64×64로 줄인 이미지), 글자 색같은 방 사람들에게 보여 주기
방 코드, 방 권한 설정, 최대 인원(선택)방 구분, 조작 권한과 인원 관리
방 비밀번호(방장이 정한 경우)와 참가할 때 입력한 비밀번호비밀번호를 아는 사람만 입장. 서버는 해시로만 메모리에 보관하며 방과 함께 삭제되고, 다른 참가자에게 전달하거나 로그로 남기지 않습니다. 확장 프로그램은 재접속에 쓰려고 메모리(브라우저를 닫으면 사라짐)에만 잠시 두고 디스크에 저장하지 않습니다.
재생 상태와 위치(재생/정지, 이동한 시각), 버퍼링·광고 대기 여부같은 위치에서 같이 재생
채팅 메시지, 입력 중 표시, 이모지 리액션, 메시지를 보낸 시점의 재생 위치같은 방 사람들에게 전달

서버는 위 정보를 방이 있는 동안 메모리에서만 다룹니다. 채팅 내용을 포함해 디스크나 데이터베이스에 저장하지 않으며, 모든 참가자가 나가고 일정 시간이 지나면, 또는 참가자가 있어도 오랫동안(약 1시간) 아무 활동이 없으면 방과 함께 사라집니다. 접속 주소(IP)는 호스팅 업체(서버 운영 환경)의 일반적인 운영 로그에 남을 수 있으며, 서비스가 따로 수집하거나 이용하지 않습니다. 초대 링크를 열면 그 방이 아직 있는지 확인하는 요청(방 코드만 전송, 존재 여부와 비밀번호 유무만 응답)이 서버로 가며, 방 코드 무작위 대입을 막으려고 접속 주소별 요청 횟수와 참가 실패(없는 방, 틀린 비밀번호) 횟수를 1분 동안만 메모리에서 셉니다.

2. 사용자 기기에 저장되는 정보

확장 프로그램은 아래 정보를 사용자의 브라우저(chrome.storage.local)에만 저장하며, 서버로 보내지 않습니다.

  • 사용자 식별자, 내 프로필(닉네임·이모지/사진·색), 채팅창 설정(크기, 위치, 모양, 투명도, 글자·프사 크기, 선택한 글꼴 이름과 즐겨찾기한 글꼴 이름, 내 컴퓨터에서 불러온 글꼴 이름 목록 등), 팝업 설정, 언어 설정
  • 프사 전환용으로 보관하는 정보: 사진 위치를 나중에 다시 맞출 수 있도록 줄여 둔 사진 원본(긴 변 512px 이하), 이모지 프사를 쓰는 동안 보관 중인 사진 프사(64×64), 사진 프사를 쓰는 동안 보관 중인 최근 이모지. 지금 쓰는 프사(64×64 또는 이모지)만 서버와 다른 참가자에게 전송되고 이 보관본은 전송되지 않으며, 프사의 "지우기"를 누르면 사진 보관본이 함께 삭제됩니다
  • 방을 나갔다가 같은 방에 다시 들어오면 이어서 볼 수 있게 하는 최근 채팅 기록(최근 일부, 일정 시간 동안만 유효)

확장 프로그램을 삭제하면 이 정보도 함께 삭제됩니다.

3. 접근하는 웹페이지

확장 프로그램은 지원하는 영상 사이트(쿠팡플레이, 넷플릭스, 웨이브, 티빙)의 페이지에서만 동작하며, 페이지 안의 영상 요소(재생 상태, 재생 위치, 광고 표시 여부)와 주소(방에 묶인 페이지를 벗어났는지 확인하는 용도)만 사용합니다. 영상 내용, 시청 기록, 계정 정보는 읽거나 전송하지 않습니다.

4. 제3자 제공과 광고

서비스는 수집한 정보를 제3자에게 판매하거나 제공하지 않고, 광고나 분석(통계) 도구를 사용하지 않습니다. 같은 방에 있는 다른 참가자에게는 1항의 정보가 전달됩니다. 방 코드나 초대 링크를 모르는 사람은 방에 들어올 수 없으니, 링크는 같이 볼 사람에게만 공유해 주세요.

5. 보관과 삭제

서버의 방 정보는 1항과 같이 방이 사라질 때 함께 삭제됩니다. 사용자는 확장 프로그램의 방 나가기, 프로필 변경, 확장 프로그램 삭제로 자신의 정보를 직접 지우거나 바꿀 수 있습니다.
