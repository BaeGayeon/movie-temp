Privacy Policy

bae-movie-temp (배무템) · Effective date: 2026-10-13 · 한국어

bae-movie-temp (the "Service") is a Chrome extension and a sync server that lets each person play a video with their own account while keeping only the playback state (play, pause, seek) in sync. The Service has no sign-up or login, and it does not collect or transmit the video itself or any of your streaming account information (ID, password, payment details, etc.).

1. Information sent to the server

When you create or join a room, the information below is sent to the sync server and passed on to the other people in the same room.

InformationPurpose
A randomly generated user ID (created by the extension when it is installed)Telling users apart in a room and reconnecting after a dropped connection
Nickname, profile emoji or profile photo (an image shrunk to 64×64), text colorShowing you to the others in the room
Room code, room permission setting, maximum number of people (optional)Telling rooms apart; managing who can control playback and how many people can join
The room password (if the host set one) and the password you type when joiningLetting only people who know the password in. The server keeps it only as a hash in memory, deletes it along with the room, and never passes it to other participants or writes it to logs. The extension keeps it only briefly in memory (gone when the browser is closed) for reconnecting, and never writes it to disk.
Playback state and position (playing/paused, the time you jumped to), whether you are buffering or waiting for an adPlaying together from the same position
Chat messages, typing indicators, emoji reactions, and the playback position when a message was sentDelivering them to the others in the room

The server handles this information in memory only, while the room exists. It does not store anything, including chat content, on disk or in a database. The room disappears some time after everyone has left, or after a long period (about 1 hour) with no activity even if people are still in it. Your IP address may remain in the hosting provider's ordinary operating logs (the server environment); the Service does not separately collect or use it. When you open an invite link, a request goes to the server to check whether that room still exists (only the room code is sent; the answer says only whether the room exists and whether it has a password). To prevent brute-forcing of room codes, the server counts requests and failed join attempts (rooms that don't exist, wrong passwords) per IP address, in memory, for 1 minute only, and it also counts the rooms created. To keep one place from opening so many connections that it overloads the server, it also counts the connections currently open per IP address, in memory, only for as long as they stay open.

2. Information stored on your device

The extension stores the information below only in your browser (chrome.storage.local) and does not send it to the server.

  • Your user ID, your profile (nickname, emoji/photo, color), chat window settings (size, position, shape, opacity, text and profile picture size, the name of the font you chose, the font names you marked as favorites, and the list of font names loaded from your computer, etc.), popup settings, and your language setting
  • Information kept for switching profile pictures: the shrunk original photo (longest side 512px or less) so you can adjust its position later, the photo profile picture (64×64) kept while you use an emoji one, and the most recent emoji kept while you use a photo one. Only the profile picture you are currently using (64×64 or an emoji) is sent to the server and the other participants; these stored copies are not sent. Pressing "Remove" on the profile picture also deletes the stored photo copies
  • Recent chat history (only a recent part, valid only for a limited time) so you can pick up where you left off when you leave a room and rejoin the same one

Uninstalling the extension deletes this information too.

3. Web pages the extension accesses

The extension works only on pages of the supported video sites (Coupang Play, Netflix, Wavve, TVING), and uses only the video element on the page (playback state, playback position, whether an ad is showing) and the page address (to check whether you have left the page the room is tied to). It does not read or transmit the video content, your viewing history, or your account information.

4. Third parties and advertising

The Service does not sell or provide the information it collects to third parties, and does not use advertising or analytics tools. The information in section 1 is passed on to the other participants in the same room. People who don't know the room code or invite link can't enter the room, so please share the link only with the people you will watch with.

5. Retention and deletion

As described in section 1, room information on the server is deleted when the room disappears. You can delete or change your own information by leaving a room, changing your profile, or uninstalling the extension.

6. Changes to this policy

If this policy changes, we will post the changes and the effective date on this page.
